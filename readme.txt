Receives invoices from OdooWoo and lets customers download them from My Account, behind the shop's own login.

== Description ==

Requires WooCommerce and an OdooWoo dashboard with invoice sending switched on. Invoices arrive as signed messages, are stored privately against the order, and are served only to the order's customer, shop managers, or the holder of a guest order's key.
